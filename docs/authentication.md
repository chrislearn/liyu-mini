# 网页登录与凭据流转

正式服务地址为 `https://liyu.taidge.com`，应用只允许该后端主机；本地演示不联网。服务端配置 `LIYU_PUBLIC_URL=https://liyu.taidge.com`。使用可信 HTTPS，反代不得记录 Authorization 头、请求体或响应中的密钥。

## 登录步骤与各方持有的信息

1. 小程序 POST `/api/v1/browser-authorizations` 创建一次授权。服务端生成独立的轮询密钥和浏览器密钥，数据库保存 SHA-256 摘要；授权五分钟后过期。小程序暂存在内存中的授权信息用于打开网页和轮询，不写入 session.json。
2. 标准 WebReader 打开后端 `/authorize/{id}#浏览器密钥`。密钥位于 URL 片段，不随网页 URL 请求送到服务器访问日志；网页再用请求体校验密钥。网页设置 no-store、no-referrer 和限制来源的 CSP，不使用到 Splash 的脚本桥。
3. 用户在后端网页输入账号密码，或在注册/联系方式修改时输入验证码。这些凭据只发送给后端，网页获得有效期十分钟的临时会话；小程序不会收到密码、验证码或这个网页会话。用户仍需点击确认授权。
4. 后端确认账号与授权用途，邮箱/手机号修改还必须匹配原账号。确认后立即撤销网页会话；小程序凭轮询密钥领取一次性授权结果。领取成功时生成独立应用会话，服务端数据库只保存其摘要；同一授权不能再次领取。
5. 应用会话用于 `Authorization: Bearer …` 调用业务 API，默认有效期 30 天。每次 API 验证会话有效期及账号启用状态；应用重启先请求 `/me` 验证，不将本地有令牌当作已成功登录。

## 令牌存储与限制

应用会话明文保存在本应用隔离存储的 `session.json`；未成功撤销的令牌明文暂存在 `revocations.json`。隔离存储限制应用间访问，**不是系统钥匙串或加密保险库**。当前标准脚本 API 没有可供本应用使用的系统安全凭据存储接口，应用不申请任意文件、进程或终端权限来绕过这个限制，也不通过把解密密钥一起保存来声称加密安全。

密码、验证码、模型密钥均不保存到这些文件。令牌不放入业务 URL、商品图片地址、AI 提示或演示数据。共享设备使用后应退出登录；不要把应用数据目录、数据库或日志当作公开材料上传。能读取本机应用数据的人仍可能获取未过期会话。

## 取消、退出和失败

- 取消授权：关闭网页并请求取消；授权超时后无法完成，旧账号切换被取消时保持旧会话。
- 退出登录：立即清除本地账号与 session.json 中的令牌，并请求后端撤销；断网时令牌进入撤销队列，下次启动或登录重试。
- 切换账号：新授权成功后替换会话并撤销旧令牌，不在授权开始时删除旧账号。
- 会话失效（401）：清除登录状态并提示重新登录；无网络或服务端失败显示错误/重试，不伪造登录成功或自动切换演示。
- 清除本地存储：不会删除服务端业务记录，也不能保证当时尚未发送成功的撤销请求得到执行。服务端过期校验继续有效。
